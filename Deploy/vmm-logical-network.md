# VMM逻辑网络配置

在部署网络控制器之前，需要在VMM中创建逻辑网络。逻辑网络是VMM中对物理网络的抽象表示，是SDN部署的`关键前置步骤`。

## 章节目标

- 在VMM中创建SDN所需的逻辑网络
- 配置逻辑交换机和上行链路端口配置文件
- 理解各逻辑网络在SDN架构中的作用

## 背景知识

VMM逻辑网络将物理网络抽象为可管理的网络资源。在SDN部署中，需要创建以下逻辑网络：

| 逻辑网络名称 | 对应子网 | 用途 |
|--------------|----------|------|
| Management | 192.148.0.0/24 | 管理网络，用于所有虚拟机的管理通信 |
| HNV Transit | 192.148.12.0/24 | HNV Provider网络，承载VXLAN封装流量 |
| PublicVIP | 192.148.15.0/24 | 公共VIP地址池，对外暴露服务 |
| PrivateVIP | 192.148.14.0/24 | 内部VIP地址池，用于内部负载均衡 |

## 创建逻辑网络

打开`Virtual Machine Manager 控制台`，进入`构造 → 网络 → 逻辑网络`。

### 创建Management逻辑网络

1. 右键点击`逻辑网络`，选择`创建逻辑网络`
2. 名称输入：`Management`
3. 在`设置`中：
   - 勾选`一个已连接的网络`
   - 勾选`允许使用此逻辑网络上的同一端口创建新VM网络`
4. 点击`网络站点`，添加网络站点：
   - 关联主机组：`所有主机`
   - 添加子网：`192.148.0.0/24`
5. 完成向导

### 创建HNV Transit逻辑网络

1. 右键点击`逻辑网络`，选择`创建逻辑网络`
2. 名称输入：`HNV Transit`
3. 在`设置`中：
   - 选择`一个已连接的网络`
   - 勾选`允许使用此逻辑网络上的同一端口创建新VM网络`
   - **勾选`由网络控制器管理的SDN网络`**
4. 点击`网络站点`，添加网络站点：
   - 关联主机组：`所有主机`
   - 添加子网：`192.148.12.0/24`
5. 完成向导

### 创建PublicVIP逻辑网络

1. 右键点击`逻辑网络`，选择`创建逻辑网络`
2. 名称输入：`PublicVIP`
3. 在`设置`中选择`一个已连接的网络`
4. 网络站点添加子网：`192.148.15.0/24`
5. 完成向导

### 创建PrivateVIP逻辑网络

1. 右键点击`逻辑网络`，选择`创建逻辑网络`
2. 名称输入：`PrivateVIP`
3. 在`设置`中选择`一个已连接的网络`
4. 网络站点添加子网：`192.148.14.0/24`
5. 完成向导

## 创建上行链路端口配置文件

在`构造 → 网络 → 端口配置文件`中：

1. 右键选择`创建Hyper-V端口配置文件`
2. 名称输入：`SDN Uplink`
3. 类型选择：`上行链路端口配置文件`
4. 网络配置中，关联之前创建的逻辑网络

## 创建逻辑交换机

在`构造 → 网络 → 逻辑交换机`中：

1. 右键选择`创建逻辑交换机`
2. 名称输入：`SDN Switch`
3. 上行链路模式选择：`嵌入式组合`（在POC环境中使用）
4. 添加上行链路端口配置文件
5. 完成向导

## 将逻辑交换机应用到计算节点

1. 在`构造 → 服务器 → 所有主机`中，选择计算节点（POC-COMP1或POC-COMP2）
2. 右键选择`属性`
3. 在`虚拟交换机`选项卡中，配置逻辑交换机

> 注意：在POC环境中使用内部虚拟交换机，此步骤的具体操作可能与生产环境有所不同。确保VMM能正确识别计算节点上的虚拟交换机。

## 检查

完成逻辑网络配置后，进行以下验证：

1. 在VMM控制台的`构造 → 网络 → 逻辑网络`中，确认四个逻辑网络均已创建
2. 每个逻辑网络的网络站点中包含正确的子网信息
3. 逻辑交换机已创建并可以分配到计算节点
