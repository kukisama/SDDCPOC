# 部署 — SDN

以下为SDN（软件定义网络）相关组件的部署章节，请在完成基础设施部署后，按照顺序逐篇阅读。

## SDN部署概述

SDN是SDDC的核心特性之一，通过软件定义的方式实现网络虚拟化、负载均衡和网关服务。SDN组件通过VMM统一部署和管理，以网络控制器（NC）为核心。

## 前置条件

在开始SDN部署之前，请确认以下条件已满足：

- [ ] VMM已安装并完成UR补丁更新
- [ ] 至少两台计算节点已被VMM纳管
- [ ] DCGW（RRAS软路由）已部署，BGP已配置
- [ ] 证书服务器（CA）已部署
