# 验证与测试

以下为部署完成后的功能验证和测试章节。

## 概述

完成所有组件部署后，需要系统性地验证各项功能是否正常工作。本章节通过实际操作验证SDN核心功能、网络虚拟化能力和负载均衡功能。

## 验证范围

| 验证项 | 说明 | 通过标准 |
|--------|------|----------|
| SDN组件状态 | NC、MUX、Gateway健康状态 | 所有组件状态正常 |
| 虚拟网络 | 创建租户虚拟网络 | 虚拟机间通信正常、网络隔离有效 |
| 负载均衡 | VIP创建和流量分发 | VIP可达、负载均匀分发 |
