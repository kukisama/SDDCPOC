# 推荐站点

以下是学习SDDC、SDN和Windows Server虚拟化相关技术的推荐资源。

## 微软官方文档

| 站点 | 说明 |
|------|------|
| [Microsoft Learn](https://learn.microsoft.com) | 微软官方学习平台，包含免费课程和动手实验 |
| [Windows Server文档](https://learn.microsoft.com/windows-server) | Windows Server官方技术文档 |
| [SDN部署指南](https://learn.microsoft.com/windows-server/networking/sdn) | 软件定义网络官方部署文档 |
| [System Center文档](https://learn.microsoft.com/system-center) | VMM和SCOM的官方文档 |
| [Hyper-V文档](https://learn.microsoft.com/windows-server/virtualization/hyper-v) | Hyper-V虚拟化技术文档 |
