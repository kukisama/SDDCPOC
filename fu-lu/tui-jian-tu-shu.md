# 推荐图书

以下图书覆盖了SDDC涉及的核心技术领域，推荐按照个人兴趣和学习需求选择阅读。

## 微软私有云

| 图书 | 作者 | 说明 |
|------|------|------|
| [《微软System Center 2012 R2私有云部署实战》](https://www.epubit.com/bookDetails?id=N11979) | 九叔 | 国内第一本系统全面讲解微软私有云构建的技术书籍，涵盖Hyper-V虚拟化、SCVMM/SCCM/SCOM部署与运维，是学习本POC项目的最佳前置读物 |

## Windows Server 与 Hyper-V

| 图书 | 作者 | 说明 |
|------|------|------|
| 《Mastering Windows Server 2019》 | Jordan Krause | 全面介绍Windows Server 2019的功能和管理 |
| 《Mastering Hyper-V》 | John Savill | 深入讲解Hyper-V虚拟化技术 |
| 《Windows Server 2019 Inside Out》 | Orin Thomas | Windows Server 2019深度技术指南 |
| 《Windows Server 2019 Cookbook》 | Mark Henderson | 以实用案例为导向的Windows Server操作指南 |

## System Center

| 图书 | 作者 | 说明 |
|------|------|------|
| 《System Center 2019 Operations Manager Cookbook》 | Steve Beaumont | SCOM实用操作手册 |
| 《Mastering System Center Configuration Manager》 | Santos Martinez等 | System Center全面指南 |

## 网络与SDN

| 图书 | 作者 | 说明 |
|------|------|------|
| 《Software Defined Networking with Windows Server and System Center》 | Greg Cusanza等 | 微软SDN技术权威指南 |
| 《计算机网络（第7版）》 | 谢希仁 | 经典计算机网络教材，理解网络基础 |
| 《TCP/IP详解》 | W. Richard Stevens | 深入理解TCP/IP协议栈 |
| 《VXLAN技术解析》 | - | 理解VXLAN封装和虚拟网络技术 |

## 云与数据中心

| 图书 | 作者 | 说明 |
|------|------|------|
| 《Mastering Azure Stack HCI》 | - | Azure Stack HCI和混合云技术指南 |
