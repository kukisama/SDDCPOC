# 环境准备

## 章节目标

完成动手实验，需要按照顺序实施以下步骤，为SDDC POC环境准备必要的硬件、软件和基础配置。

## 本章概述

在开始部署SDDC之前，需要完成一系列环境准备工作。这些准备工作涵盖硬件资源评估、软件获取、网络规划和基础约定，是后续所有部署工作的基础。

| [软件配置](../SoftwareRequirements.md) | 所需ISO文件和软件清单 | 必读 |
| [嵌套虚拟化（Azure）注意事项](../NESTED.md) | 在Azure VM中运行POC的特殊配置 | 按需 |

| [IP地址和虚拟机名称约定](../IPandVMname.md) | VM命名、IP规划和子网设计 | 必读 |
| [网络规划详解](../NetworkPlanning.md) | 各网段功能详解和交互关系 | 推荐 |

## 前置条件汇总

开始动手之前，请确认以下条件：

- [ ] 准备好满足最低配置要求的物理主机或Azure VM
- [ ] 获取所需的软件ISO文件（Windows Server 2019、SQL Server、System Center）
- [ ] 阅读并理解IP地址和账号体系规划
- [ ] 了解嵌套虚拟化的概念和配置方法（如在虚拟化环境中部署）
