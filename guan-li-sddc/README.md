# 管理SDDC

完成SDDC POC环境的部署后，本章节介绍日常管理和运维的方法。SDDC的管理涉及多个工具和平台，了解每个工具的适用场景和操作方法，是高效运维的基础。

## 管理工具总览

| 工具 | 主要用途 | 管理范围 |
|------|----------|----------|
| Virtual Machine Manager（VMM） | 虚拟化平台管理 | 虚拟机生命周期、计算/存储/网络资源、SDN组件 |
| Operations Manager（SCOM） | 监控与告警 | 所有服务器和服务的健康状态、性能指标 |
| Windows Admin Center（WAC） | 轻量级Web管理 | 服务器管理、Hyper-V管理、SDN概览 |
| PowerShell | 自动化管理 | 几乎所有管理操作的自动化和批量处理 |

## 日常运维流程

SDDC日常运维主要包括以下工作：

1. **监控检查**：每日检查SCOM告警，确认所有组件健康
2. **虚拟机管理**：根据业务需求创建、迁移、调整虚拟机资源
3. **网络管理**：管理虚拟网络、负载均衡规则和访问控制策略
4. **补丁管理**：定期更新操作系统和System Center组件的补丁
5. **备份与恢复**：确保关键配置和数据的备份策略正常执行
