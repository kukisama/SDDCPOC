# 软件使用

本章节介绍SDDC环境中核心管理软件的界面和基本操作方法，帮助读者快速上手日常管理工作。

## Virtual Machine Manager 控制台

VMM是SDDC的核心管理工具，提供图形化界面管理整个虚拟化平台。

### 启动VMM控制台

在`POC-VMM01`或任意安装了VMM控制台的管理主机上：

1. 打开`Virtual Machine Manager 控制台`
2. 服务器名称输入`POC-VMM01.contoso.com:8100`
3. 点击`连接`

### VMM控制台主要区域

VMM控制台分为以下几个功能区域：

| 区域 | 功能 | 常用操作 |
|------|------|----------|
| VM和服务 | 虚拟机管理 | 创建/启动/停止/迁移虚拟机，部署服务 |
| 构造 | 基础设施管理 | 管理主机、网络、存储、逻辑网络 |
| 库 | 模板和资源库 | 管理虚拟机模板、ISO、脚本、配置文件 |
| 作业 | 任务监控 | 查看所有VMM操作的执行状态和历史 |
| 设置 | 系统设置 | 配置运行方式帐户、用户角色等 |

### 常用操作提示

- 使用`作业`视图可以跟踪所有异步操作的进度和结果
- 右键菜单提供了大部分常用操作的快速入口
- 使用`PowerShell`选项卡可以查看VMM操作对应的PowerShell命令

## Operations Manager 控制台

SCOM提供全面的监控和告警能力。

### 启动SCOM控制台

在`POC-OM01`或任意安装了SCOM控制台的管理主机上打开`Operations Manager控制台`。

### SCOM控制台主要区域

| 区域 | 功能 | 常用操作 |
|------|------|----------|
| 监视 | 实时监控 | 查看活动告警、性能视图、仪表板 |
| 创作 | 监控规则 | 创建自定义规则和监视器 |
| 管理 | 系统管理 | 管理Agent、管理包、通知 |
| 报告 | 报表功能 | 生成性能报告和可用性报告 |

### 日常监控流程

1. 打开`监视 → 活动警报`，检查是否有新的告警
2. 对于`严重`级别的告警，立即排查处理
3. 对于`警告`级别的告警，根据告警说明评估影响
4. 处理完成后，关闭或确认告警

## Windows Admin Center

Windows Admin Center（WAC）是微软推荐的现代化服务器管理工具，通过Web浏览器提供管理界面。

### 访问WAC

在浏览器中访问WAC的URL（通常为`https://管理服务器名称:443`或自定义端口），使用域账号登录。

### WAC主要功能

| 功能 | 说明 |
|------|------|
| 服务器管理 | 查看服务器概览、进程、服务、存储、网络等 |
| Hyper-V管理 | 管理虚拟机、虚拟交换机 |
| 事件查看器 | 查看Windows事件日志 |
| PowerShell | 远程PowerShell会话 |
| 远程桌面 | 通过浏览器进行RDP连接 |

> 提示：WAC会持续更新新功能，包括SDN管理扩展。建议使用最新版本以获得最佳体验。
